# Industrial Machine Vision Inspection & Automation

**Technical internship case study | ABW Technologies, Malaysia | March–October 2026**

> A confidentiality-safe overview of my experience supporting automated optical inspection systems in manufacturing.

## Overview

During my Computer Science internship, I contributed to the configuration, testing, troubleshooting, and software support of industrial machine vision inspection workflows. This case study focuses on my learning and technical responsibilities rather than proprietary implementation details.

## Technologies and concepts

- **Software:** Python, C#, Visual Studio, WPF, PyQt/PySide GUI concepts
- **Vision:** VisionMaster, image acquisition, regions of interest (ROI), inspection workflow configuration
- **Integration:** PLC communication concepts, inspection status and result interfaces
- **Quality:** Repeat testing, false-call investigation, missed-defect investigation, debugging

## Problem and approach

Automated visual inspection must distinguish acceptable products from defects while maintaining consistent operation. In practice, inspection performance depends on camera acquisition, positioning, inspection parameters, software behavior, and repeatable testing.

My work involved helping test and troubleshoot these connected elements. A typical investigation followed this cycle:

1. Observe the inspection result and identify an unexpected behavior.
2. Review relevant image regions, workflow settings, and software status.
3. Adjust or test one relevant parameter or software behavior under supervision as appropriate.
4. Re-run checks and compare the results.
5. Communicate findings and document follow-up actions.
